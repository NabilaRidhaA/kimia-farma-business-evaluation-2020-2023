# kimia-farma-business-evaluation-2020-2023
Proyek portofolio analisis big data untuk mengevaluasi kinerja bisnis Kimia Farma (2020-2023). Proyek ini mencakup penggabungan dan pemrosesan dataset menggunakan Google BigQuery (SQL), serta perancangan dashboard interaktif di Google Looker Studio untuk menyajikan metrik pendapatan, profitabilitas, dan kinerja kantor cabang.
